# Example — One AI, One Session

A single agent may perform multiple logical roles.

## 1. Design
The user provides a product requirement: "Add legal entity management."

The agent creates a checkpoint contract and explicitly ends Design.

## 2. Delivery
After the contract is accepted, the same session transitions to Delivery, inspects the repository, and implements only that checkpoint.

The contract remains fixed unless repository evidence exposes a real conflict. A conflict is reported; it is not an excuse for silent scope expansion.

## 3. Review
The same session can self-review, but it must label this as self-review, not independent review.

For high-risk work, use a separate reviewer or human before starting the next checkpoint.
