# Changelog

## 0.1.0 — 2026-08-20

Initial public preview, refined in-place during the v0.1 preview:
- model- and session-agnostic Design / Deliver / Review roles;
- persistent `checkpoint start` / `checkpoint stop` user control;
- checkpoint, implementation handoff, and review contracts;
- repository-first and verification-sized checkpoint rules;
- compact evidence-first communication discipline;
- test-first behavior-change guidance where practical;
- root-cause-first debugging discipline;
- fresh verification before completion claims;
- composition rules for specialized third-party skills without making them dependencies;
- quality gates and checkpoint sizing references;
- single-session, multi-agent, full-stack, migration, and start/stop examples;
- pressure scenarios and deterministic package validator.
