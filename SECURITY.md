# Security

This repository contains an Agent Skill: instructions that may influence how an AI coding agent acts.

## Reporting

If you find behavior that could cause unsafe repository modification, secret exposure, destructive commands, authorization weakening, or misleading verification claims, please open a GitHub issue without including sensitive data.

For a private vulnerability report, use GitHub's private vulnerability reporting feature if enabled.

## Trust model

Installing a skill is equivalent to trusting procedural instructions. Review third-party skills before installation and use your agent/runtime's permission controls and sandboxing.

This skill does not replace tool permissions, repository protections, code review, secret scanning, or human approval for destructive/high-risk actions.
